# Security policy

This is an educational lab repository, not a hosted service with a formal vulnerability-response SLA.

Do not publish API keys, tokens, kubeconfigs, private endpoints, exploit details that expose a live deployment, or sensitive prompts in a public issue. If you find a security problem in this repository, contact the repository owner privately through GitHub and include only the information needed to reproduce it safely.

For secure configuration, agent/MCP boundaries, deployment controls, and credential handling, read [docs/SECURITY.md](docs/SECURITY.md).
